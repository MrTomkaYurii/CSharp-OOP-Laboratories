# Лабораторна робота №09: Узагальнення (Generics) у C# (.NET 10)

## 🎯 Мета роботи
Вивчення та практичне опанування концепції **узагальнень (Generics)** в C#:
- Створення узагальнених класів (`Generic Classes`) та структур даних;
- Розробка узагальнених методів (`Generic Methods`) для роботи з довільними типами;
- Застосування обмежень параметрів типу (`Generic Constraints`), зокрема `where T : IComparable<T>`;
- Реалізація інтерфейсу `IEnumerable<T>` в кастомних колекціях;
- Створення власних структур зв'язування даних фіксованої розмірності (`Tuple`, `Threeuple`).

---

## 📋 Перелік практичних завдань

| Проект | Назва завдання | Архітектура та опис завдання |
| :---: | :--- | :--- |
| **00** | **Узагальнена коробка (Generic Box)** | Базовий узагальнений клас `Box<T>`, що інкапсулює значення будь-якого типу та перевизначає `ToString()` у форматі `{Type}: {Value}`. |
| **01** | **Коробка для рядків (Generic Box of String)** | Демонстрація роботи `Box<string>` для збереження та форматованого виводу текстових даних. |
| **02** | **Коробка для чисел (Generic Box of Integer)** | Демонстрація збереження цілих чисел `Box<int>` без втрати швидкодії на операціях пакування/розпакування (boxing/unboxing). |
| **03** | **Узагальнений метод обміну рядків (Generic Swap Method Strings)** | Реалізація узагальненого методу `Swap<T>(IList<T> list, int index1, int index2)` для обміну елементів у колекції `Box<string>`. |
| **04** | **Узагальнений метод обміну чисел (Generic Swap Method Integers)** | Застосування узагальненого методу `Swap<T>` до списку об'єктів `Box<int>`. |
| **05** | **Підрахунок більших рядків (Generic Count Method Strings)** | Узагальнений метод порівняння `CountGreaterThan<T>(IList<T> list, T element) where T : IComparable<T>` для підрахунку кількості елементів, більших за вказаний. |
| **06** | **Підрахунок більших чисел з плаваючою комою (Generic Count Method Doubles)** | Тестування узагальненого методу підрахунку на числах подвійної точності `double`. |
| **07** | **Користувацький список (Custom List)** | Створення узагальненої структури даних `CustomList<T> where T : IComparable<T>` з підтримкою операцій `Add`, `Remove`, `Contains`, `Swap`, `CountGreaterThan`, `Max`, `Min`. |
| **08** | **Сортувальник списку (Custom List Sorter)** | Додавання можливості сортування `CustomList<T>` за допомогою узагальненого алгоритму сортування `Sorter.Sort(CustomList<T>)`. |
| **09** | **Ітератор списку (Custom List Iterator)** | Реалізація інтерфейсів `IEnumerable<T>` та `IEnumerator<T>` у `CustomList<T>` для можливості обходу колекції через цикл `foreach`. |
| **10** | **Кортеж (Tuple)** | Створення власного узагальненого типу `Tuple<T1, T2>` для повернення та зберігання пари значень різного типу. |
| **11** | **Трійка значень (Threeuple)** | Розширення ідеї кортежів до трикомпонентної структури `Threeuple<T1, T2, T3>` для зберігання складніших зв'язок (наприклад, адреса, банківські реквізити). |
