# Лабораторна робота №19: Розширені зв'язки в Entity Framework Core (.NET 10)

## 🎯 Мета роботи
Вивчення та практичне застосування **розширених зв'язків (Advanced Entity Relations)** та відокремленої конфігурації сутностей в **Entity Framework Core 9 (.NET 10)**:
- Організація модульної конфігурації через реалізацію інтерфейсу `IEntityTypeConfiguration<T>`;
- Моделювання поліморфних платіжних методів (`PaymentMethod`) з взаємовиключними зовнішніми ключами (`BankAccountId` та `CreditCardId`);
- Створення унікальних складених індексів для валідації бізнес-правил на рівні СУБД;
- Реалізація бізнес-логіки оплати рахунків (`PayBills`) з пріоритетним списанням коштів з банківських рахунків та кредитних карток.

---

## 📋 Перелік практичних завдань

| Проект | Назва компонента | Архітектура та опис системи |
| :---: | :--- | :--- |
| **01** | **Моделі даних (BillsPaymentSystem.Data.Models)** | Доменні сутності системи оплати рахунків: <br>• `User` (ідентифікатор, ПІБ, пошта, пароль).<br>• `PaymentMethod` (тип `PaymentMethodType`, навігація до користувача, банківського рахунку чи кредитки).<br>• `BankAccount` (баланс, назва банку, SWIFT, методи поповнення та зняття коштів).<br>• `CreditCard` (ліміт, заборгованість, залишок ліміту, дата завершення дії). |
| **02** | **Шар доступу до даних (BillsPaymentSystem.Data)** | Контекст `BillsPaymentSystemContext` та конфігураційні класи: <br>• `UserConfiguration` — налаштування розмірів полів та кодування.<br>• `PaymentMethodConfiguration` — налаштування зв'язків та унікальних індексів.<br>• `BankAccountConfiguration` та `CreditCardConfiguration` — правила відображення фінансових сутностей.<br>• Міграція `Initial`. |
| **03** | **Клієнтський додаток (BillsPaymentSystem.App)** | Консольний інтерфейс користувача: <br>• Запит та форматований вивід фінансового профілю користувача за ID (`User Details`).<br>• Процедура оплати рахунків `PayBills(userId, amount)`: каскадне списання коштів спочатку з усіх доступних банківських рахунків, а залишок — з ліміту кредитних карток. |

## 🛠️ Як зібрати та запустити

```powershell
# Збірка всього рішення лабораторної
dotnet build "Lab19-EFCore-Advanced-Relations/OOP - Lab19.sln" -c Release

# Запуск консольного додатку системи оплати рахунків
dotnet run --project "Lab19-EFCore-Advanced-Relations/BillsPaymentSystem.App/BillsPaymentSystem.App.csproj"
```
