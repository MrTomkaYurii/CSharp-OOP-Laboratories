# Лабораторна робота №01: Вступ до програмування мовою C# (.NET 10)

## 🎯 Мета роботи
Вивчення та закріплення основних концепцій програмування мовою C# на платформі .NET: базові типи даних, оператори розгалуження, цикли, арифметичні операції та робота з консольним введенням/виведенням.

---

## 📋 Перелік практичних завдань

| Проект | Назва завдання | Опис алгоритму |
| :---: | :--- | :--- |
| **05** | **Цілі числа (Integer Types)** | Вибір оптимального цілочисельного типу (`sbyte`, `byte`, `short`, `ushort`, `int`, `uint`, `long`, `ulong`) для поданих числових значень. |
| **06** | **Числа з плаваючою точкою (Floating Point)** | Порівняння точності чисел `float`, `double` та банківського типу `decimal`. |
| **07** | **Символи та рядки (Chars & Strings)** | Робота з символами `char`, рядками `string`, escape-послідовностями та приведенням типів `object`. |
| **08** | **Середнє значення (Average)** | Зчитування трьох чисел з консолі та обчислення їх середнього арифметичного. |
| **09** | **Площа трапеції (Trapezoid Area)** | Обчислення площі трапеції за формулою: $S = \frac{a + b}{2} \cdot h$. |
| **10** | **Остання цифра (Last Digit)** | Отримання останньої цифри цілого числа через залишок від ділення `% 10`. |
| **11** | **$n$-та цифра (N-th Digit)** | Пошук $n$-ї цифри числа з кінця за допомогою операцій ділення та взяття залишку. |
| **12** | **Велике і непарне (Big and Odd)** | Перевірка двох умов: чи є число більшим за 20 і одночасно непарним (`n > 20 && n % 2 != 0`). |
| **13** | **Чистий дільник (Pure Divisor)** | Перевірка кратності числа 9, 11 або 13 без залишку. |
| **14** | **Найбільше з трьох (Biggest of Three)** | Знаходження максимального з трьох чисел за допомогою вкладених умов `if-else` або `Math.Max`. |
| **15** | **Знак добутку (Sign of Product)** | Визначення знаку добутку трьох дійсних чисел (`+`, `-`, `0`) без виконання безпосереднього множення. |
| **16** | **Число як день тижня (Day of Week)** | Конвертація номера дня тижня (1–7) у його українську назву за допомогою оператора `switch`. |
| **17** | **Обчислити факторіал $N!$ (Factorial)** | Обчислення факторіала цілого числа $N$ за допомогою циклу `for` та типу даних `BigInteger` для запобігання переповненню. |

## 🛠️ Як зібрати та запустити

```powershell
# Збірка всього рішення лабораторної
dotnet build "Lab01-Introduction/OOP-Lab01.sln" -c Release

# Запуск конкретного завдання (наприклад, Завдання 14)
dotnet run --project "Lab01-Introduction/14/14.csproj"
```
