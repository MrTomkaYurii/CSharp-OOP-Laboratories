# Лабораторна робота №04: Робота з абстракцією в C# (.NET 10)

## 🎯 Мета роботи
Опанування абстрагування даних та поведінки: виділення сутностей, розділення відповідальностей, перерахування (`enum`), статичні класи-калькулятори та рефакторинг процедурного спагеті-коду у виразні об'єктні моделі.

---

## 📋 Перелік практичних завдань

| Проект | Назва завдання | Архітектура та опис завдання |
| :---: | :--- | :--- |
| **01** | **Точка в прямокутнику (Point in Rectangle)** | Класи `Point` (координати $X, Y$) та `Rectangle` (верхня ліва та нижня права точки). Метод `Contains(Point point)` інкапсулює логіку перевірки попадання точки в межі фігури. |
| **02** | **Готельне бронювання (Hotel Reservation)** | Використання перерахувань (`enum SeasonMultiplier`, `enum DiscountPercentage`) та статичного класу `PriceCalculator` для обчислення фінальної вартості проживання з урахуванням сезонних коефіцієнтів та знижок. |
| **03** | **Лікарня (Hospital)** | Декомпозиція складної системи розподілу пацієнтів між відділеннями (`Department`), палатами (`Room`, місткістю до 3 пацієнтів) та лікарями (`Doctor`). Фільтрація та сортування за палатами і списками пацієнтів лікаря. |
| **04** | **Жадібні часи (Greedy Times)** | Об'єктний рефакторинг алгоритмічної задачі про грабіжника: клас сумки `Bag`, поліморфна ієрархія предметів (`Item`, `GoldItem`, `GemItem`, `CashItem`) зі строгими правилами балансу ($Gold \ge Gem \ge Cash$) та обмеженням максимальної місткості. |

---

