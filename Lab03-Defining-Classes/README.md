# Лабораторна робота №03: Визначення класів, інкапсуляція та конструктори в C# (.NET 10)

## 🎯 Мета роботи
Опанування базових принципів об'єктно-орієнтованого програмування в C#: проектування класів, інкапсуляція стану через приватні поля та публічні властивості, ланцюжки конструкторів (Constructor Chaining), композиція та агрегація об'єктів.

---

## 📋 Перелік практичних завдань

| Проект | Назва завдання | Опис завдання та архітектура |
| :---: | :--- | :--- |
| **01** | **Визначення класу Person (Define a Class Person)** | Створення класу `Person` із приватними полями `name` та `age`, публічними властивостями та демонстрація інлайн-ініціалізації екземплярів. |
| **02** | **Створення конструкторів (Creating Constructors)** | Реалізація трьох конструкторів із використанням `this(...)` для повторного використання коду (дефолтний "No name"/1 рік, за віком, повний). |
| **03** | **Найстарший член сім'ї (Oldest Family Member)** | Клас `Family`, що інкапсулює список `List<Person>`, метод додавання `AddMember` та пошук найстаршого члена через LINQ/ітерацію `GetOldestMember`. |
| **04** | **Опитування громадської думки (Opinion Poll)** | Зчитування інформації про людей, фільтрація за умовою `Age > 30` та впорядкування результатів за алфавітом. |
| **05** | **Модифікатор дат (Date Modifier)** | Клас `DateModifier` для обчислення абсолютної різниці в днях між двома довільними датами за допомогою `DateTime.ParseExact`. |
| **06** | **Реєстр компанії (Company Roster)** | Клас `Employee` з обов'язковими та опціональними полями (`email`, `age`), групування працівників за відділами та пошук відділу з найвищою середньою зарплатою. |
| **07** | **Швидкісні перегони (Speed Racing)** | Клас `Car` з відстеженням витрат пального (`FuelAmount`, `FuelConsumptionPerKm`), пробігу та методом переміщення `Drive(distance)`. |
| **08** | **Необроблені дані (Raw Data)** | Комплексна модель автомобіля з композицією класів: `Engine`, `Cargo`, масив із 4 `Tire`, фільтрація за типами вантажу та тиском у шинах. |
| **09** | **Перетин прямокутників (Rectangle Intersection)** | Клас `Rectangle` з перевіркою перетину двох фігур у 2D просторі за координатами вершин та розмірами. |
| **10** | **Продавець автомобілів (Car Salesman)** | Модель зв'язку `Car` та `Engine` з різними варіаціями конструкторів та красивим рядковим представленням `ToString()`. |
| **11** | **Тренер покемонів (Pokemon Trainer)** | Класи `Trainer` та `Pokemon`, турнірна система перевірки наявності стихії (`Fire`, `Water`, `Electricity`) або зменшення здоров'я. |
| **12** | **Google (Комплексне досьє персони)** | Моделювання великого профілю `Person`, що агрегує класи `Company`, `Car`, `List<Parent>`, `List<Child>`, `List<Pokemon>`. |
| **13** | **Генеалогічне дерево (Family Tree)** | Парсинг складних взаємозв'язків між батьками та дітьми за іменами та датами народження з побудовою дерева родини. |
| **14** | **Котяча леді (Cat Lady)** | Ієрархія котів: базовий клас `Cat` та похідні підвиди `Siamese`, `Cymric`, `StreetExtraordinaire` з унікальними характеристиками. |
| **15** | **Інструмент малювання (Drawing Tool)** | Абстрактний клас `Figure` та похідні `Square`, `Rectangle` з побудовою графічних рамок символами у консолі. |

```powershell

# Запуск завдання 06 (Company Roster)
dotnet run --project "Lab03-Defining-Classes/06. Company Roster/06.CompanyRoster.csproj"
```
