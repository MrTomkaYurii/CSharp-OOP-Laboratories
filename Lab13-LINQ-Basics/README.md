# Лабораторна робота №13: Основи LINQ в C# (.NET 10)

## 🎯 Мета роботи
Глибоке практичне засвоєння технології **Language Integrated Query (LINQ)** у C#:
- Синтаксис запитів (`Query Syntax`) та синтаксис методів розширення (`Fluent / Method Syntax`);
- Фільтрація даних (`Where`), проекція (`Select`), сортування (`OrderBy`, `ThenByDescending`);
- Агрегація та підрахунок значень (`Count`, `Sum`, `Average`, `Min`, `Max`);
- Групування даних (`GroupBy`, `group ... by ... into`);
- Об'єднання джерел даних (`Join ... on ... equals ...`);
- Генерація та експорт звітів у формат Microsoft Excel за допомогою бібліотеки `EPPlus`.

## 📋 Перелік практичних завдань

| Проект | Назва завдання | Архітектура та опис завдання |
| :---: | :--- | :--- |
| **01** | **Студенти за групами (Students by Group)** | Фільтрація списку студентів за номером групи (`Group == 2`) та сортування за ім'ям за допомогою LINQ `where` та `orderby`. |
| **02** | **Студенти за ім'ям та прізвищем (Students by First and Last Name)** | Вибірка студентів, у яких ім'я лексикографічно передує прізвищу (`FirstName.CompareTo(LastName) < 0`). |
| **03** | **Студенти за віком (Students by Age)** | Фільтрація студентів у віковому діапазоні від 18 до 24 років із формуванням проекції (`FirstName`, `LastName`, `Age`). |
| **04** | **Сортування студентів (Sort Students)** | Багаторівневе впорядкування: спочатку за прізвищем за зростанням, а при збігу — за ім'ям за спаданням (`OrderBy` / `ThenByDescending`). |
| **05** | **Фільтр за поштовим доменом (Filter Students by Email Domain)** | Вибірка студентів з адресами електронної пошти на домені `@gmail.com` через предикат `EndsWith`. |
| **06** | **Фільтр за номером телефону (Filter Students by Phone)** | Пошук студентів з телефонними номерами з префіксом міста Софія (`02` або `+3592`). |
| **07** | **Студенти-відмінники (Excellent Students)** | Знаходження студентів, які мають хоча б одну відмінну оцінку (бал 6), з виводом їхніх імен та переліку оцінок. |
| **08** | **Студенти зі слабкими оцінками (Weak Students)** | Пошук студентів, у яких щонайменше дві оцінки менші або дорівнюють 3 (`Count(grade <= 3) >= 2`). |
| **09** | **Студенти, зараховані у 2014 або 2015 роках** | Витяг оцінок студентів, чий факультетський номер завершується на `14` або `15`. |
| **10** | **Групування за групами (Group by Group)** | Застосування оператора `group by` для розподілу студентів за навчальними групами та впорядкування самих груп. |
| **11** | **Об'єднання зі спеціальностями (Students Joined to Specialties)** | Операція з'єднання двох колекцій `join ... on ... equals ...` за спільним факультетським номером. |
| **12** | **Маленький Джон (Little John)** | Парсинг стріл різного розміру (`>----->`, `>>----->`, `>>>----->`) через регулярні вирази, бінарне кодування та паліндромні бітові операції. |
| **13** | **Канцелярія компаній (Office Stuff)** | Складна ієрархічна агрегація через словники та LINQ: `Company ➔ Product ➔ Total Amount` із форматованим виводом підсумків. |
| **14** | **Експорт в Excel (Export to Excel)** | Читання масиву даних студентів (`StudentData.txt`) та динамічна генерація електронної таблиці `.xlsx` за допомогою modern EPPlus для .NET 10. |
