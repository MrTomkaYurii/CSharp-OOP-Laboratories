# Лабораторна робота №06: Успадкування та перевизначення членів в C# (.NET 10)

## 🎯 Мета роботи
Вивчення та практичне закріплення механізмів **успадкування (Inheritance)** в C#: розширення базових класів, виклик базових конструкторів через `: base(...)`, перевизначення віртуальних методів (`virtual`, `override`), модифікатор доступу `protected` та ієрархія винятків.

---

## 📋 Перелік практичних завдань

| Проект | Назва завдання | Архітектура та опис завдання |
| :---: | :--- | :--- |
| **01** | **Людина та Дитина (Person and Child)** | Базовий клас `Person` з обмеженням віку $Age \ge 0$. Похідний клас `Child`, який перевизначає логіку валідації та накладає додаткове обмеження: вік дитини не може перевищувати 15 років. |
| **02** | **Книжковий магазин (Book Shop)** | Базовий клас `Book` з валідацією імені автора та ціни. Похідний клас `GoldenEditionBook`, який перевизначає властивість `Price`, автоматично додаючи 30% до базової вартості книги. |
| **03** | **Людство (Mankind)** | Абстрактний або базовий клас `Human` (ім'я, прізвище з валідацією великої літери). Похідні класи: `Student` (номер студентського квитка 5–10 символів) та `Worker` (тижнева зарплата, години роботи та погодинна оплата). |
| **04** | **База даних онлайн-радіо (Online Radio Database)** | Спеціалізована ієрархія кастомних винятків (`InvalidSongException` ➔ `InvalidArtistNameException`, `InvalidSongLengthException` ➔ `InvalidSongMinutesException`, `InvalidSongSecondsException`). Парсинг тривалості пісень та підрахунок сумарного часу плейлиста `hh:mm:ss`. |
| **05** | **Жорстокий план Мордору (Mordor's Cruel Plan)** | Моделювання настрою Гендальфа залежно від спожитої їжі: базовий клас `Food` та його нащадки (`Lembas`, `Apple`, `HoneyCake`, `Mushrooms`). Фабричні класи `FoodFactory` та `MoodFactory` для розрахунку очок щастя та зміни настрою (`Angry`, `Sad`, `Happy`, `JavaScript`). |
| **06** | **Тварини (Animals)** | Базовий клас `Animal` з інтерфейсом `ISoundProducable`. Похідні класи `Dog`, `Frog`, `Cat`, а також специфічні підвиди `Kitten` (завжди Female) та `Tomcat` (завжди Male), які поліморфно реалізують власний звук `ProduceSound()`. |

## 🛠️ Як зібрати та запустити

```powershell
# Збірка всього рішення лабораторної
dotnet build "Lab06-Inheritance/OOP - Lab06.sln" -c Release

# Запуск завдання 04 (Online Radio Database)
dotnet run --project "Lab06-Inheritance/04. Online Radio Database/03.OnlineRadioDatabase.csproj"
```
