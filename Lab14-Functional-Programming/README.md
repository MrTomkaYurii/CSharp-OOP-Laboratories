# Лабораторна робота №14: Функціональне програмування в C# (.NET 10)

## 🎯 Мета роботи
Опанування парадигми **функціонального програмування (Functional Programming)** засобами сучасної платформи .NET:
- Робота зі стандартними узагальненими делегатами `Action<T>`, `Func<T, TResult>` та `Predicate<T>`;
- Створення чистих функцій (Pure Functions), анонімних методів та лямбда-виразів (`lambda expressions`);
- Композиція функцій та предикатів (Function Composition, Higher-Order Functions);
- Кастомні компаратори та функції вищого порядку (наприклад, `TriFunction`);
- Функціональна фільтрація та трансформація незмінних колекцій.

---

## 📋 Перелік практичних завдань

| Проект | Назва завдання | Архітектура та опис завдання |
| :---: | :--- | :--- |
| **01** | **Точка дії (Action Point)** | Базове використання делегата `Action<string>` для покрокового виводу елементів текстового масиву в консоль. |
| **02** | **Лицарі честі (Knights of Honor)** | Застосування `Action<string>` для додавання титулу `"Sir "` до кожного імені перед друком. |
| **03** | **Кастомна функція мінімуму (Custom Min Function)** | Реалізація власної функції пошуку найменшого числа у масиві через делегат `Func<int[], int>` без використання вбудованого `Min()`. |
| **04** | **Пошук парних чи непарних чисел (Find Evens or Odds)** | Використання `Predicate<int>` для фільтрації діапазону чисел за ознакою парності/непарності. |
| **05** | **Прикладна арифметика (Applied Arithmetics)** | Функціональний конвеєр обробки числових масивів за командами (`add`, `multiply`, `subtract`, `print`) через передачу делегатів `Func<int, int>` та `Action<int[]>`. |
| **06** | **Реверс та виключення (Reverse and Exclude)** | Комбінація реверсу послідовності та виключення елементів, що діляться на задане число, за допомогою `Predicate<int>`. |
| **07** | **Предикат для імен (Predicate for Names)** | Фільтрація списку імен за критерієм максимальної довжини за допомогою параметризованого предиката `Predicate<string>`. |
| **08** | **Кастомний компаратор (Custom Comparator)** | Сортування масиву цілих чисел за допомогою лямбда-компаратора `Array.Sort(arr, (x, y) => ...)`: парні числа розташовуються першими за зростанням, після них — непарні за зростанням. |
| **09** | **Список предикатів (List of Predicates)** | Композиція списку предикатів `List<Predicate<int>>` для пошуку чисел у діапазоні $1..N$, що одночасно діляться на всі дільники з наданого набору. |
| **10** | **Вечірка предикатів (Predicate Party!)** | Динамічне дублювання або видалення гостей вечірки за предикатами (`StartsWith`, `EndsWith`, `Length`). |
| **11** | **Модуль фільтрів бронювання (Party Reservation Filter Module)** | Реєстр активних фільтрів гостей: збереження, додавання та видалення складних правил фільтрації перед фінальним виводом. |
| **12** | **Пекельне полум'я III (Inferno III)** | Складна система фільтрації самоцвітів на основі суми сусідніх очок (предикати `Sum Left`, `Sum Right`, `Sum Left & Right`). |
| **13** | **Три-функція (TriFunction)** | Реалізація функції вищого порядку, що приймає іншу функцію як аргумент: знаходження першого імені, сума ASCII-кодів літер якого більша або дорівнює порогу $N$. |
