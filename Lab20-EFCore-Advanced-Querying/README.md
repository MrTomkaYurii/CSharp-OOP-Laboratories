# Лабораторна робота №20: Поглиблені запити в Entity Framework Core (.NET 10)

## 🎯 Мета роботи
Практичне освоєння **поглиблених запитів (Advanced Querying)** в **Entity Framework Core 9 (.NET 10)**:
- Використання складних фільтрів (`Where`), проекцій (`Select`) та сортування (`OrderBy`, `ThenBy`);
- Зв'язування відношень багато-до-багатьох (`BookCategory`) та робота з навігаційними властивостями;
- Групування та агрегація даних (`GroupBy`, `Sum`, `Count`);
- Оптимізація запитів та уникнення N+1 проблеми;
- Масові оновлення (`Bulk Update`) та масові видалення (`Bulk Delete`) записів у базі даних.

## 📋 Перелік практичних завдань (BookShop)

| Проект | Назва завдання | Архітектура та опис завдання |
| :---: | :--- | :--- |
| **01** | **Вікові обмеження (Age Restriction)** | Отримання списку назв книг за віковим цензом (`Minor`, `Teen`, `Adult`) через парсинг перелічення `AgeRestriction`. |
| **02** | **Золоті книги (Golden Books)** | Пошук книг золотого видання (`EditionType.Gold`) з накладом менше 5000 примірників. |
| **03** | **Книги за ціною (Books by Price)** | Вибірка назв та цін книг з вартістю понад $40, впорядкованих за спаданням ціни. |
| **04** | **Книги, не видані у вказаний рік (Not Released In)** | Фільтрація книг, рік виходу яких відрізняється від переданого користувачем року. |
| **05** | **Книги за категоріями (Book Titles by Category)** | Запит книг, що належать хоча б до однієї з переданого списку категорій через перетин зв'язків. |
| **06** | **Книги, видані до дати (Released Before Date)** | Вибірка книг з датою релізу раніше за `dd-MM-yyyy` із впорядкуванням за датою виходу. |
| **07** | **Пошук авторів (Author Search)** | Пошук авторів, чиє ім'я закінчується на заданий підрядок (`FirstName.EndsWith(...)`). |
| **08** | **Пошук книг (Book Search)** | Пошук назв книг, що містять зазначений фрагмент тексту (регістронезалежний пошук). |
| **09** | **Пошук книг за прізвищем автора (Book Search by Author)** | Знаходження книг авторів, чиє прізвище починається на вказаний підрядок (`LastName.StartsWith(...)`). |
| **10** | **Підрахунок книг (Count Books)** | Підрахунок кількості книг, довжина назви яких строго перевищує $N$ символів. |
| **11** | **Загальний наклад автора (Total Book Copies)** | Агрегація загальної кількості копій книг для кожного автора, відсортована за сумою копій спадно. |
| **12** | **Прибуток за категоріями (Profit by Category)** | Розрахунок загального грошового виторгу (`Price * Copies`) для кожної категорії книг. |
| **13** | **Найновіші книги за категоріями (Most Recent Books)** | Проекція топ-3 найновіших книг для кожної окремої категорії, відсортованих за роком випуску. |
| **14** | **Підвищення цін (Increase Prices)** | Масове оновлення цін книг (+$5), виданих до 2010 року, за допомогою збереження змін контексту. |
| **15** | **Видалення книг (Remove Books)** | Масове каскадне видалення з бази даних усіх книг, тираж яких менший за 4200 примірників. |
