# Лабораторна робота №11: Рефлексія та кастомні атрибути в C# (.NET 10)

## 🎯 Мета роботи
Поглиблене вивчення метапрограмування в .NET за допомогою **рефлексії (Reflection)** та **користувацьких атрибутів (Custom Attributes)**:
- Динамічне дослідження метаданих типів, конструкторів, приватних полів та методів під час виконання (`System.Type`, `FieldInfo`, `MethodInfo`, `BindingFlags`);
- Динамічне створення екземплярів класів через `Activator.CreateInstance`;
- Реалізація розширюваного патерну Команда (Command Pattern) за допомогою динамічного пошуку класів команд за їхніми іменами;
- Побудова власного простого механізму впровадження залежностей (Dependency Injection Container) на основі маркерного атрибута `[Inject]`;
- Створення, конфігурація та читання метаданих через кастомні атрибути (`AttributeUsage`, `Attribute.GetCustomAttribute`).

## 📋 Перелік практичних завдань

| Проект | Назва завдання | Архітектура та опис завдання |
| :---: | :--- | :--- |
| **01** | **Збір полів (Harvesting Fields)** | Використання `BindingFlags` для динамічного вибіркового перегляду полів класу: тільки приватних (`private`), захищених (`protected`), публічних (`public`) або всіх (`all`) без зміни коду цільового класу. |
| **02** | **Чорна скринька цілих чисел (Black Box Integer)** | Доступ до закритої інкапсуляції класу `BlackBoxInteger`: виклик `NonPublic` методів (`Add`, `Subtract`, `Multiply`, `Divide` тощо) та читання приватного поля `innerValue` через рефлексію. |
| **03** | **Військові бараки — Фабрика (BarracksWars - A New Factory)** | Реалізація рефлексивної фабрики юнітів `UnitFactory`: створення екземплярів (`Archer`, `Pikeman`, `Swordsman`) за назвою типу з автоматичним пошуком у просторі імен без жорстких `switch/case`. |
| **04** | **Військові бараки — Патерн Команда (BarracksWars - Commands Strike Back)** | Архітектура Command Pattern на рефлексії: динамічна інтерпретація команд користувача (`add`, `report`, `fight`, `retire`) шляхом зіставлення імені команди з класом `IExecutable`. |
| **05** | **Військові бараки — Впровадження залежностей (BarracksWars - Return of the Dependencies)** | Створення атрибута `[Inject]` та кастомного механізму IoC (Inversion of Control), який автоматично впроваджує необхідні репозиторії та фабрики в поля команд через рефлексію. |
| **06** | **Світлофори (Traffic Lights)** | Моделювання роботи світлофора (`Red` ➔ `Green` ➔ `Yellow` ➔ `Red`) та циклічна зміна станів колекції сигналів за допомогою рефлексії над переліченнями `Enum`. |
| **07** | **Пекельна безкінечність (Inferno Infinity)** | Комплексна модульна система модифікації зброї (`Axe`, `Sword`, `Knife`) самоцвітами (`Ruby`, `Emerald`, `Amethyst`) різної чистоти (`Chipped`, `Regular`, `Flawless`). Рефлексивний командний інтерпретатор. |
| **08** | **Кастомний атрибут класу (Create Custom Class Attribute)** | Розробка кастомного атрибута `[Class("Author", Revision, "Description", Reviewers)]` з обмеженням на класи. Вичитування та форматований вивід метаданих про авторів і ревізію на вимогу користувача. |
| **09** | **Рефакторинг пекельної безкінечності (Inferno Infinity Refactoring)** | Поглиблений архітектурний рефакторинг проекту 07 з винесенням абстракцій введення/виведення (`IReader`, `IWriter`) згідно з принципом інверсії залежностей (DIP). |
