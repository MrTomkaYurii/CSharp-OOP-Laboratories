# Лабораторна робота №02: Основи роботи з масивами в C# (.NET 10)

## 🎯 Мета роботи
Вивчення та закріплення навичок роботи з одновимірними масивами в мові C#: ініціалізація, циклічний обхід, зсув елементів, алгоритми пошуку, фільтрації та обчислення агрегованих значень.

---

## 📋 Перелік практичних завдань

| Проект | Назва завдання | Опис завдання та алгоритм |
| :---: | :--- | :--- |
| **01** | **Найбільший спільний кінець (Largest Common End)** | Порівняння двох рядкових масивів зліва направо та справа наліво для знаходження максимальної послідовності однакових слів з початку або кінця. |
| **02** | **Обертання і сума (Rotate and Sum)** | Циклічний зсув масиву вправо на $k$ позицій та покрокове накопичення суми результуючих масивів за формулою $(i + r) \% n$. |
| **03** | **Скласти і підсумувати (Fold and Sum)** | Згортання масиву розміром $4k$: перші та останні $k$ елементів перевертаються та попарно додаються до центральних $2k$ елементів. |
| **04** | **Решето Ератосфена (Sieve of Eratosthenes)** | Класичний алгоритм знаходження всіх простих чисел у діапазоні від 1 до $N$ з використанням булевого масиву маркерів. |
| **05** | **Порівняння масивів символів (Compare Char Arrays)** | Лексикографічне порівняння двох масивів символів з виведенням того, який розташований раніше за алфавітним порядком. |
| **06** | **Максимальна послідовність однакових елементів (Max Sequence of Equal Elements)** | Знаходження найдовшої неперервної послідовності однакових цілих чисел у масиві. |
| **07** | **Максимальна послідовність зростаючих елементів (Max Sequence of Increasing Elements)** | Пошук найдовшої монотонно зростаючої неперервної підпослідовності. |
| **08** | **Найчастіше число (Most Frequent Number)** | Визначення числа, яке найчастіше зустрічається у вхідному масиві; у разі рівності частот обирається найлівіше. |
| **09** | **Індекс букв (Index of Letters)** | Створення масиву з 26 літер англійського алфавіту (`'a'`..`'z'`) та знаходження індексу кожної літери введеного користувачем слова. |
| **10** | **Пари за різницею (Pairs by Difference)** | Підрахунок кількості пар чисел $(a, b)$ у масиві, абсолютна різниця між якими дорівнює заданому числу $d$ ($|a - b| = d$). |
