# Лабораторна робота №08: Поліморфізм у C# (.NET 10)

## 🎯 Мета роботи
Глибоке практичне вивчення фундаментального принципу ООП — **поліморфізму (Polymorphism)**:
- Використання динамічного поліморфізму (динамічної диспетчеризації) через ключові слова `virtual`, `override` та `abstract`;
- Побудова розширюваних архітектур з поліморфною обробкою колекцій об'єктів різних похідних типів;
- Реалізація патернів проектування Factory (`AnimalFactory`, `FoodFactory`) для інкапсуляції створення поліморфних екземплярів;
- Застосування безпечної перевірки типів та обробки виняткових ситуацій під час роботи з поліморфними контрактами.

---

## 📋 Перелік практичних завдань

| Проект | Назва завдання | Архітектура та опис завдання |
| :---: | :--- | :--- |
| **01** | **Транспортні засоби (Vehicles)** | Базовий абстрактний клас `Vehicle` із загальними властивостями палива та розходу. Похідні класи `Car` (+0.9 л/км на кондиціонер) та `Truck` (+1.6 л/км на кондиціонер, витік палива при заправці — потрапляє лише 95%). Поліморфні операції `Drive(distance)` та `Refuel(liters)`. |
| **02** | **Розширення транспортних засобів (Vehicles Extension)** | Додавання місткості бака `TankCapacity` та валідації переповнення. Створення класу `Bus` з підтримкою режимів поїздки: з пасажирами (кондиціонер увімкнено, +1.4 л/км) та без пасажирів (`DriveEmpty`, без додаткового споживання). |
| **03** | **Дика ферма (Wild Farm)** | Комплексна поліморфна система взаємодії тварин та їжі: <br>• Ієрархія тварин: `Animal` ➔ `Bird` (`Owl`, `Hen`), `Mammal` (`Mouse`, `Dog`), `Feline` (`Cat`, `Tiger`).<br>• Ієрархія їжі: `Food` ➔ `Vegetable`, `Fruit`, `Meat`, `Seeds`.<br>• Поліморфні звуки `ProduceSound()` та раціони харчування (тигри їдять тільки м'ясо, коти — овочі та м'ясо, курчата — будь-яку їжу) з різними коефіцієнтами набору ваги. |
