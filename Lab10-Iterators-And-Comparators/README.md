# Лабораторна робота №10: Ітератори та компаратори в C# (.NET 10)

## 🎯 Мета роботи
Вивчення та практичне застосування механізмів **ітерації (Iterators)** та **порівняння об'єктів (Comparators)** у C#:
- Реалізація інтерфейсів `IEnumerable<T>` та `IEnumerator<T>` з використанням конструкції `yield return`;
- Реалізація контракту природного сортування через `IComparable<T>` (`CompareTo`);
- Створення зовнішніх стратегій сортування через інтерфейс `IComparer<T>` (патерн *Strategy*);
- Коректне перевизначення методів `Equals` та `GetHashCode` для узгодженої поведінки в хеш-таблицях (`HashSet<T>`) та бінарних деревах пошуку (`SortedSet<T>`).

---

## 📋 Перелік практичних завдань

| Проект | Назва завдання | Архітектура та опис завдання |
| :---: | :--- | :--- |
| **01** | **Список-ітератор (ListyIterator)** | Клас `ListyIterator<T>`, що інкапсулює внутрішній масив елементів та підтримує операції переміщення вказівника `Move()`, перевірки наявності наступного `HasNext()` та друку поточного `Print()`. |
| **02** | **Колекція (Collection)** | Розширення `ListyIterator<T>` реалізацією `IEnumerable<T>` з використанням `yield return` та додаванням команди `PrintAll` для послідовного виводу всіх елементів. |
| **03** | **Стек (Stack)** | Кастомна структура даних LIFO `Stack<T>` з методами `Push` і `Pop`. Реалізація `IEnumerable<T>` для дворазового проходу по стеку через `yield return`. |
| **04** | **Жабка (Froggy)** | Моделювання стрибків жабки по камінцях через колекцію `Lake : IEnumerable<int>`: обхід спочатку всіх елементів з парними індексами (0, 2, 4...), а потім непарних. |
| **05** | **Порівняння об'єктів (Comparing Objects)** | Реалізація `IComparable<Person>` у класі `Person` (послідовне порівняння імені, віку та міста). Пошук збігів екземплярів у колекції та вивід статистики. |
| **06** | **Патерн Стратегія (Strategy Pattern)** | Створення двох незалежних компараторів `IComparer<Person>`: `NameComparator` (довжина імені, а при рівності — регістронезалежний перший символ) та `AgeComparator` (за віком) для роздільного сортування у двох `SortedSet`. |
| **07** | **Логіка рівності (Equality Logic)** | Порівняння поведінки об'єктів у хеш-структурах (`HashSet<Person>`) та деревах (`SortedSet<Person>`). Забезпечення узгодженості між `IComparable<T>`, `Equals()` та `GetHashCode()`. |
| **08** | **Ветеринарні клініки (Pet Clinics)** | Моделювання клініки з непарною кількістю кімнат: специфічний алгоритм розміщення пацієнтів від центральної кімнати назовні та звільнення кімнат з підтримкою перебору палат. |
| **09** | **Обхід зв'язаного списку (Linked List Traversal)** | Власна реалізація двозв'язного списку `LinkedList<T>` з підтримкою швидкого додавання/видалення та ітеруванням через `yield return`. |
