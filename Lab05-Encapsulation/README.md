# Лабораторна робота №05: Інкапсуляція та валідація даних в C# (.NET 10)

## 🎯 Мета роботи
Вивчення та практичне застосування фундаментального принципу ООП — **інкапсуляції**: приховування внутрішнього стану об'єктів, захист інваріантів через аксесори властивостей (`get`/`set`), викидання змістовних винятків (`ArgumentException`) у разі спроби встановити некоректні дані та валідація бізнес-правил.

---

## 📋 Перелік практичних завдань

| Проект | Назва завдання | Опис завдання та правила валідації |
| :---: | :--- | :--- |
| **01** | **Клас Коробка (Class Box)** | Створення класу `Box` з полями `length`, `width`, `height`. Методи обчислення площі повної поверхні (`SurfaceArea`), бічної поверхні (`LateralSurfaceArea`) та об'єму (`Volume`). |
| **02** | **Валідація даних коробки (Class Box Data Validation)** | Додавання валідації властивостей: сторони мають бути строго більшими за нуль (`value <= 0 ➔ ArgumentException`). Захист інваріантів геометричного тіла. |
| **03** | **Ферма тварин (Animal Farm)** | Моделювання класу курки `Chicken` з обмеженням віку (0–15 років) та непустим ім'ям. Приватний метод розрахунку продуктивності яєць на день залежно від віку курки. |
| **04** | **Шопінг-лихоманка (Shopping Spree)** | Класи `Person` та `Product` з валідацією імен (не пусті) та бюджету/ціни (не можуть бути від'ємними). Моделювання процесу купівлі з перевіркою достатності коштів. |
| **05** | **Калорійність піци (Pizza Calories)** | Складна система розрахунку калорій: клас `Pizza`, тісто `Dough` (тип борошна, техніка випікання, вага) та начинки `Topping`. Модифікатори калорійності залежно від інгредієнтів зі строгою валідацією діапазонів ваги. |
| **06** | **Генератор футбольних команд (Football Team Generator)** | Класи `Team` та `Player`. Гравець має 5 статистик (0–100): `Endurance`, `Sprint`, `Dribble`, `Passing`, `Shooting`. Команда веде облік гравців та автоматично розраховує загальний рейтинг майстерності. |

---

## 🛠️ Як зібрати та запустити

```powershell
# Збірка всього рішення лабораторної
dotnet build "Lab05-Encapsulation/OOP - Lab05.sln" -c Release

# Запуск завдання 05 (Pizza Calories)
dotnet run --project "Lab05-Encapsulation/05. Pizza Calories/03.PizzaCalories.csproj"
```
