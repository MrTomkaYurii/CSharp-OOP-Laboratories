# Лабораторна робота №17: Entity Framework Core — Підхід Code First (.NET 10)

## 🎯 Мета роботи
Вивчення та практичне застосування технології ORM **Entity Framework Core 9 (.NET 10)** з використанням підходу **Code First**:
- Моделювання сутностей доменної області C# (`POCO Classes`);
- Конфігурація схеми бази даних за допомогою **Fluent API** у методі `OnModelCreating`;
- Налаштування типів зв'язків: один-до-багатьох (1:N) та багато-до-багатьох (N:M через проміжну таблицю);
- Створення, застосування та модифікація міграцій (`EF Core Migrations`);
- Генерація тестових наборів даних (`Mock / Seed Data Generators`).

---

## 📋 Перелік практичних завдань

| Проект | Назва завдання | Архітектура та опис завдання |
| :---: | :--- | :--- |
| **01** | **База даних госпіталю (Hospital Database)** | Моделювання системи обліку пацієнтів госпіталю: <br>• Сутності: `Patient`, `Visitation`, `Diagnose`, `Medicament`.<br>• Проміжна таблиця для відношення багато-до-багатьох `PatientMedicament`.<br>• Конфігурація обмежень довжини, обов'язковості полів, підтримки Unicode через Fluent API.<br>• Генератори випадкових пацієнтів, адрес, діагнозів та призначень для заповнення бази. |
| **02** | **Модифікація бази даних госпіталю (Hospital Database Modification)** | Розширення схеми: додавання сутності лікаря `Doctor` (`DoctorId`, `Name`, `Specialty`). Зв'язування відвідувань `Visitation` з конкретним лікарем (відношення 1:N) та оновлення контексту бази даних. |
| **03** | **База даних продажів (Sales Database)** | Проектування системи обліку продажів магазину: <br>• Сутності: `Customer`, `Product`, `Store`, `Sale`.<br>• Створення початкової міграції `Initial`.<br>• Еволюція схеми через міграції: додавання стовпця опису товару `Description` (`ProductsAddColumnDescription`) та встановлення значення за замовчуванням `GETDATE()` для дати продажу (`SalesAddDateDefault`). |
