# Лабораторна робота №07: Інтерфейси та абстракція в C# (.NET 10)

## 🎯 Мета роботи
Глибоке практичне засвоєння концепції **інтерфейсів (Interfaces)** та **абстракції (Abstraction)** в C#:
- Визначення контрактів поведінки через інтерфейси (`interface`);
- Множинна реалізація інтерфейсів одним класом;
- Явна реалізація інтерфейсів (`Explicit Interface Implementation`) для вирішення конфліктів сигнатур і приховування деталей;
- Побудова складних ієрархій контрактів (наприклад, у військовій структурі `Military Elite`);
- Реалізація структур даних зі спеціалізованими інтерфейсами додавання/видалення (`Collection Hierarchy`).

---

## 📋 Перелік практичних завдань

| Проект | Назва завдання | Архітектура та опис завдання |
| :---: | :--- | :--- |
| **01** | **Визначення інтерфейсу IPerson (Define an Interface IPerson)** | Створення інтерфейсу `IPerson` (властивості `Name` та `Age`). Клас `Citizen`, що реалізує інтерфейс, та демонстрація використання посилань на інтерфейс замість конкретного типу. |
| **02** | **Множинна реалізація (Multiple Implementation)** | Розширення контракту громадянина: створення інтерфейсів `IIdentifiable` (`Id`) та `IBirthable` (`Birthdate`). Реалізація класом `Citizen` одночасно трьох інтерфейсів: `IPerson`, `IIdentifiable`, `IBirthable`. |
| **03** | **Феррарі (Ferrari)** | Створення інтерфейсу `ICar` з методами `Brakes()` та `Gas()`. Реалізація класу `Ferrari` (модель "488-Spider"), що інкапсулює ім'я водія та реалізує специфічні звуки гальмування та розгону. |
| **04** | **Телефонія (Telephony)** | Інтерфейси `ICallable` (`Call(string number)`) та `IBrowsable` (`Browse(string url)`). Клас `Smartphone` реалізує обидва інтерфейси з валідацією (телефон містить лише цифри, URL не містить цифр). |
| **05** | **Прикордонний контроль (Border Control)** | Створення інтерфейсу `IIdentifiable` (`Id`). Класи `Citizen` та `Robot` реалізують інтерфейс. Система фільтрації затриманих за суфіксом фейкового ідентифікатора (перевірка підозрілих ID на кордоні). |
| **06** | **Святкування днів народження (Birthday Celebrations)** | Інтерфейс `IBirthable` (`Birthdate`). До моделі міста додаються тварини `Pet`. Прикордонники шукають усіх істот (громадян і домашніх тварин), що народилися у вказаний рік. |
| **07** | **Дефіцит їжі (Food Shortage)** | Інтерфейс `IBuyer` (`Name`, `Food`, метод `BuyFood()`). Громадяни купують їжу порціями по 10 одиниць, повстанці `Rebel` — по 5 одиниць. Підрахунок загальної купленої їжі за списком імен покупців. |
| **08** | **Військова еліта (Military Elite)** | Комплексна об'єктна ієрархія військових: `ISoldier`, `IPrivate`, `ISpecialisedSoldier`, `ILieutenantGeneral`, `IEngineer`, `ICommando`, `ISpy`. Команди, місії (`Repair`, `Mission`), валідація корпусів (`Airforces`, `Marines`) та статусів місій. |
| **09** | **Ієрархія колекцій (Collection Hierarchy)** | Інтерфейси колекцій `IAddCollection`, `IAddRemoveCollection`, `IMyList`. Створення класів `AddCollection` (додавання в кінець), `AddRemoveCollection` (додавання на початок, видалення з кінця) та `MyList` (видалення з початку, відстеження `Used`). |
| **10** | **Явна реалізація інтерфейсів (Explicit Interfaces)** | Два інтерфейси з однаковою сигнатурою методу: `IPerson.GetName()` та `IResident.GetName()`. Клас `Citizen` реалізує обидва через явну реалізацію (`Explicit Interface Implementation`), демонструючи уникнення колізій імен. |
